# Asset Pipeline

## Rule

Maps must be clean background art. They must not contain HUD, labels, progress bars, buttons, text, or baked UI.

HUD and gameplay UI are built as separate HTML/CSS layers using transparent PNG icons and props.

## Runtime Asset Locations

```text
app/public/assets/art/maps/
app/public/assets/art/3d/
```
