# Production Plan

## North Star

Create a polished Google Play-ready portrait idle/tycoon game with a premium casual 3D look and a long retention loop.

## Core Player Loop

1. Boats catch fish automatically.
2. Fish fills storage.
3. Player sells fish or spends it on orders.
4. Coins upgrade boats, market, storage, pier, workshop, lighthouse, aquarium.
5. Lighthouse opens new maps and fish types.
6. Orders grant coins and village stars.
7. Aquarium collection gives permanent production bonuses.
8. Sea Festival resets run progress for pearls.
9. Pearls accelerate the next run.

## Visual Direction

- Bright 3D casual mobile style.
- Chunky cream/gold/blue UI panels.
- Saturated turquoise water.
- Toy-like boats and buildings.
- Large readable icons.
- Animated scene layer: water shimmer, boat bobbing, flying gulls, floating reward labels.
